# Offline check on a real phone (pilot item 12)

For K-12 EdTech or a regional champion. It takes about 40 minutes. Use one low-cost Android phone of the kind pilot learners use, with Chrome and a working SIM card or Wi-Fi.

## Before you start

- [ ] Write down the phone model, the Android version and the amount of free storage.
- [ ] Have a test learner account that is in a pilot class, with recorded school and parent or guardian consent. Write down the learner's K12Plus ID.
- [ ] A pilot teacher (or an administrator) has opened **Offline lessons** and tapped **Mark as checked** on at least one lesson for the learner's grade.
- [ ] Note the time you start.

## 1. Install and save a lesson (with a signal)

- [ ] Open k12plus.app in Chrome and log in as the test learner.
- [ ] Chrome menu: **Add to Home screen**. The K12Plus icon appears on the home screen.
- [ ] Open the app from the home screen and tap **Offline lessons** (in the menu).
- [ ] The checked lesson is listed, with **Download for offline (about 2 KB)**. Draft lessons are not listed.
- [ ] Tap **Download for offline**. It changes to **Saved on this phone**.

## 2. Use it with no signal

- [ ] Turn on **Aeroplane mode** (and make sure Wi-Fi is off).
- [ ] Close the app completely (swipe it away from recent apps), then open it again from the home screen. **It must open.**
- [ ] Open **Offline lessons**. The screen says **No signal. Saved lessons still work**.
- [ ] Open the saved lesson. Read **Learn**, then **Examples**.
- [ ] In **Practise**, answer every question. Get at least two wrong on purpose first. Try a decimal comma (for example 2,5) and a fraction (for example 3/4) where they fit. Tap **Show a hint** once.
- [ ] At the end you see **Lesson complete** and **Next for you**. Write down the "right first time" score.
- [ ] Go to **Assessments**, then **Quizzes**, and finish one quiz. Write down the score.
- [ ] Ask the agent one question in the chat. The reply says the question has been saved.
- [ ] Open **Offline lessons** again. The line at the top says how many items are waiting to be sent. Write the number down.
- [ ] Turn the phone off and on again. Open the app: the lesson progress and the waiting number are still there.

## 3. Sync (with a signal)

- [ ] Turn off Aeroplane mode. Open the app and wait one minute with it on screen.
- [ ] **Offline lessons** now says **Online. Everything is up to date.**
- [ ] The chat shows the agent's answer to the saved question.
- [ ] Note the time you finish.

## 4. Check the server

Send the learner's K12Plus ID and the start and finish times to the developer, who checks that the server holds exactly:

- [ ] 1 lesson record and one practice record per question, with the same "right first time" score as on the phone, all marked as done offline
- [ ] 1 quiz result with the same score
- [ ] 1 agent question (not two)

## Checking lesson packs (for teachers)

Lesson packs are drafts until a pilot teacher, a champion or an administrator checks them. To check one, log in, open **Offline lessons**, open the lesson and read **Learn**, **Examples** and every question in **Practise**, including the hints and "How to do it". If everything is correct and suitable for the class, go back and tap **Mark as checked**. Learners see the lesson from then on. If something is wrong, do not check it; send the lesson name and the question number to K-12 EdTech, and a corrected version will come back for checking.
